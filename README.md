# Oceanographic_drivers_gopher_rockfish
Repository for the manuscript "Linking Oceanographic Drivers to Historical Recruitment for a Nearshore, Spring-Spawning Rockfish Allows Forecasts of Population Dynamics in a Changing Ocean"


## Order of code 

1. "ROMS_historical" and "ROMS_future" are markdowns that clean the netCDF files from the ROMS-NEMUCSC and select for the spatial habitat of gopher rockfish. The ROMS outputs are available via person contact (see below). The product of this code is within the data folder to be used to run the analysis
2. Manuscript_analysis.rmd is a markdown that contains all the analyses used in the paper
